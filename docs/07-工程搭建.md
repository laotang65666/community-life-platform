# 07 · 工程搭建

> 版本:v1.0
> 目标:在 IDEA 里从零建出 8 个 Maven 模块,能编译、能启动。
> 你负责建文件和包,本文档负责告诉你 **建什么、导什么、放哪**。

---

## 1. 开工前检查

| 项 | 要求 | 检查方式 |
|---|---|---|
| JDK | **21**(LTS) | `java -version` |
| Maven | 3.9+ | `mvn -v` |
| IDEA | 2023.3+ | — |
| Lombok | 插件已启用 | Settings → Plugins |
| 注解处理 | 已开启 | Settings → Build → Compiler → Annotation Processors → ✅ Enable |

**IDEA 全局设置**

- Project SDK:21
- Project language level:21
- File encoding:UTF-8(全部)
- Maven → Runner → VM Options 可不改

---

## 2. 第一步:建父工程

**操作**

1. `File → New → Project`
2. 左侧选 **Maven**(不要选 Spring Initializr)
3. 填写:

   | 项 | 值 |
   |---|---|
   | Name | `community-life-platform` |
   | Location | `Desktop/面向社区用户的生活服务平台` |
   | GroupId | `com.laotang` |
   | ArtifactId | `community-life-platform` |
   | Version | `1.0-SNAPSHOT` |

4. 创建后 **删掉父工程下的 `src` 目录**(父工程只做聚合,不写代码)。

> 不要用 Spring Initializr 建父工程——它生成的是单模块应用,后面拆模块很麻烦。

---

## 3. 第二步:建 8 个模块

在项目根上右键 → `New → Module` → 选 **Maven** → 填 ArtifactId。

**按这个顺序建**(依赖从下往上):

| 顺序 | 模块名 | 说明 |
|---|---|---|
| 1 | `clp-common` | 公共:Result、异常、常量、枚举、工具 |
| 2 | `clp-parameter` | 入参 / 出参 DTO |
| 3 | `clp-id-generator` | 雪花 ID |
| 4 | `clp-framework-redis` | Redis、缓存、限流 |
| 5 | `clp-framework-lock` | Redisson、延迟队列 |
| 6 | `clp-framework-mq` | Kafka 封装 |
| 7 | `clp-framework-ai` | Spring AI、Agent |
| 8 | `clp-core-service` | 业务主模块(可启动) |

每个模块建好后,IDEA 一般会自动把父工程写进 `<parent>`。没写的话手动补。

## 7. 第六步:启动类与配置

### 7.1 启动类

位置:`clp-core-service/src/main/java/com/laotang/core/CoreServiceApplication.java`

```java
package com.laotang.core;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication(scanBasePackages = "com.laotang")
public class CoreServiceApplication {

    public static void main(String[] args) {
        SpringApplication.run(CoreServiceApplication.class, args);
    }
}
```

> **`scanBasePackages` 必须写全 `com.laotang`。**
> 启动类在 `com.laotang.core`,默认只扫这个包,扫不到 `com.laotang.framework.*` 下的框架 Bean。

> **不要写 `@MapperScan("com.laotang.core.**.mapper")`。**
> MyBatis 的 `basePackages` 不认识 `**` 通配,这条会扫描失败。
> 正确做法:每个 Mapper 接口上加 `@Mapper`,自动配置会扫描启动类所在包及子包。

### 7.2.1 本地敏感配置:application-local.yml

**原则:能提交的进 `application.yml`,不能提交的进 `application-local.yml`。**

`application.yml`(进 Git):

```yaml
spring:
  profiles:
    active: local
  datasource:
    password: ${MYSQL_PASSWORD:}
  data:
    redis:
      password: ${REDIS_PASSWORD:}
```

`application-local.yml`(**不进 Git**):

```yaml
spring:
  datasource:
    password: 你的 MySQL 密码
  data:
    redis:
      password: 你的 Redis 密码
```

`.gitignore` 已加入:

```gitignore
**/application-local.yml
```

**新人拉下代码后:**

```bash
cp clp-core-service/src/main/resources/application-local.yml.example \
   clp-core-service/src/main/resources/application-local.yml
# 然后填入本地密码
```

## 9. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 启动报 `DataSource` 相关错误 | 没起 MySQL 或库没建 | 建库 `clp`,检查账号密码 |
| 框架模块的 Bean 注入不到 | `scanBasePackages` 没写全 | 改成 `com.laotang` |
| Lombok 报找不到 getter | 注解处理没开 | Settings → Annotation Processors |
| `@RequestParam` 拿不到名字 | 编译没加 `-parameters` | 父 POM 已加,检查是否生效 |
| Redisson 和 Lettuce 冲突 | 两个 Redis starter 都生效 | 确认 `RedisAutoConfiguration` 已退让,或只用 Redisson 连接 |
| Knife4j 与 springdoc 版本冲突 | 两者都引了 springdoc | **先只用 springdoc**,Knife4j 后续再加 |
| Spring AI 启动报模型配置缺失 | 没设 `DEEPSEEK_API_KEY` | 配置环境变量 |
| 循环依赖启动失败 | 模块分层被破坏 | 修依赖,不要开 `allow-circular-references` |
