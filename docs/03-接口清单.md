## 7. 优惠券 / 秒杀

| 方法 | 路径 | 说明 | 角色 | 幂等 |
|---|---|---|---|---|
| POST | `/api/v1/vouchers` | 商户创建秒杀券 | 商户本人 | — |
| GET | `/api/v1/vouchers` | 优惠券列表 | 公开 | — |
| GET | `/api/v1/vouchers/{voucherId}` | 优惠券详情 | 公开 | — |
| POST | `/api/v1/vouchers/{voucherId}/seckill-tokens` | 申请秒杀令牌 | USER | — |
| POST | `/api/v1/vouchers/{voucherId}/orders` | 秒杀下单 | USER | ✅ 必带 Key |
| GET | `/api/v1/vouchers/{voucherId}/my-order` | 我的秒杀订单 | USER | — |

**秒杀链路**

```
① POST /seckill-tokens   → 返回 token(60s 有效)
② POST /orders           → 携带 token + Idempotency-Key
                       → Redis+Lua 原子扣减
                       → Kafka 异步落库
③ GET  /my-order         → 查询结果(可轮询)
```

```jsonc
// POST /vouchers/{id}/seckill-tokens
{ }  // 无请求体
// → { "token": "sk_9f3c...", "expiresIn": 60 }

// POST /vouchers/{id}/orders
{ "token": "sk_9f3c..." }
// → 202 Accepted
{ "orderNo": "20261017120000123456", "status": "PROCESSING" }
```

> 秒杀下单为异步:接口返回 `202`,最终结果通过 `GET /my-order` 或 WebSocket `SECKILL_RESULT` 获取。

```jsonc

```

**发送消息**

```jsonc
{
  "content": "本小区最近有什么商品?"
}
```

**响应**

```jsonc
{
  "code": 0,
  "data": {
    "conversationId": "1843920128374123008",
    "messageId": "1843920192837465000",
    "content": "下单后 30 分钟未支付会自动关闭。[1]",
    "tokensIn": 410,
    "tokensOut": 199,
    "createdAt": "2026-10-17T20:38:14+08:00",
    "sources": [
      {
        "docId": "seed:user-order",
        "title": "下单与订单规则",
        "section": "取消与超时",
        "score": 0.971
      }
    ],
    "degraded": false
  }
}
```

**AI 错误码**

| code | 说明 |
|---|---|
| 10001 | 会话不存在或不属于当前用户 |
| 10002 | 当前角色无权使用该助手 |
| 10003 | 消息内容过长 |
| 10004 | AI 服务暂时不可用 |
| 10005 | 会话正在处理中(并发锁) |
| 1003 | 触发单用户每分钟限流 |
