# 商品与订单履约

## 商品管理
- 商户可以为自己的店铺新增商品,设置名称、价格(单位:分)、库存。
- 商品默认上架(ON_SALE),可以下架(OFF_SALE)或逻辑删除。
- 修改商品使用乐观锁(version),并发修改冲突时需要重试。
- 下架商品不会出现在公开商品列表中,但历史订单快照不受影响。

## 订单履约
- 商户只能查看和处理自己店铺的订单。
- 订单状态为 PAID 时,商户可以接单,状态变为 ACCEPTED。
- ACCEPTED 后商户完成履约,订单变为 COMPLETED。
- 商户接单、完成都会给用户推送站内通知。
- CREATED 状态的订单不需要商户处理:用户未支付,30 分钟后会自动关闭。

## 经营数据
- 今日订单数:今天创建的订单总数。
- 成交订单数/成交额:今天创建且状态为 PAID、ACCEPTED、COMPLETED 的订单。
- 待接单数:当前状态为 PAID 的订单数。

## 注意
- 平台不提供线上结算,结算规则以运营通知为准。
- 不要承诺审核时间、结算到账时间。
