# 优惠券与秒杀

## 优惠券
- 优惠券由商户创建,包含面额、开始时间、结束时间。
- 优惠券状态由时间和库存实时计算:未开始、进行中、已结束、已抢完。
- 优惠券库存以 Redis 计数为准,数据库做最终审计。

## 秒杀流程
1. 用户先获取秒杀令牌,令牌 60 秒内有效,每个用户对同一张券的获取次数有限。
2. 携带令牌和 Idempotency-Key 发起抢购。
3. 服务端通过 Redis + Lua 原子完成:校验令牌、一人一单、库存扣减。
4. 抢购成功后异步落库,结果通过站内通知推送。

## 常见错误码
- 7001:秒杀未开始。
- 7002:秒杀已结束。
- 7003:秒杀库存不足。
- 7004:重复抢购,受一人一单限制。
- 7005:秒杀令牌无效或已使用。
- 7006:秒杀请求过于频繁。

## 注意
- 秒杀订单也是订单,成功后可以在订单相关页面查看。
- 不要向用户承诺一定能抢到,库存以服务端结果为准。
- 令牌过期后需要重新获取,不要重复使用旧令牌。
