# 账号与登录

## 登录方式
- 平台使用手机号加短信验证码登录,首次登录会自动注册。
- 验证码有效期 5 分钟;同一手机号发送过于频繁会返回 3003。
- 登录成功后返回 accessToken(30 分钟)和 refreshToken(7 天)。
- accessToken 过期后使用 refreshToken 刷新;登出后 refreshToken 失效。

## 账号安全
- 客服不会索取短信验证码、密码、支付密码、银行卡号。
- 不要点击站外链接完成支付或退款。
- 账号异常、被封禁等问题需要转人工客服核实。

## 角色
- USER:普通用户。
- MERCHANT:通过入驻审核的商户,同时拥有用户权限。
- ADMIN:平台管理员。
- 商户审核通过后需要重新登录,新角色才会写入 token。
