# 签到与积分

## 签到
- 每个自然日可签到一次,重复签到返回错误码 9001。
- 签到使用 Redis Bitmap 记录,数据库 tb_sign 做审计。
- 每日签到加 5 积分。
- 连续签到每满 7 天,额外加 20 积分。

## 积分
- 积分变动记录在 tb_point_log,流水只增不改。
- 积分流水包含来源(SIGN_IN 签到 / SIGN_IN_STREAK 连续签到奖励)和业务 ID。
- 积分余额可以在"我的-积分"查看,AI 也可以帮用户查询。

## 注意
- 积分兑换功能首期未开放。
- 不要承诺积分可以提现、转让或抵扣现金。
- 签到记录按月份存储,查询本月签到可以看签到页面。
