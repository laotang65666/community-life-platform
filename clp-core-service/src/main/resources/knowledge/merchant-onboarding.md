# 商户入驻

## 流程
1. 用户提交入驻申请:店铺名称、营业执照号、地址、联系人、联系电话。
2. 管理员审核。审核中不能重复提交,重复提交返回 4002。
3. 审核通过后系统自动创建店铺,用户角色升级为 MERCHANT。
4. 审核驳回会记录驳回原因,修改后可以重新提交。

## 注意
- 审核通过后需要重新登录,才能拿到 MERCHANT 权限。
- 一个商户对应一家店铺。
- 店铺初始状态为营业中(OPEN)。
- 查询入驻进度可以查看"我的商户信息"。

## 常见错误码
- 4001:商户信息不存在。
- 4002:已有审核中的入驻申请。
- 4003:商户审核未通过。
- 4005:您已经是商户。
