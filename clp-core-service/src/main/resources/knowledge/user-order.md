# 下单与订单规则

## 下单
- 用户只能对同一店铺的商品统一下单,平台不支持跨店合并下单。
- 下单必须携带 Idempotency-Key;重复提交同一个 key 返回同一笔订单,不会重复扣库存。
- 商品库存不足时下单失败,错误码 5003。
- 店铺必须处于营业中(OPEN)状态才能下单。

## 支付
- 平台当前为模拟支付,支付成功后订单状态从 CREATED 变为 PAID。
- 支付后等待商家接单,商家接单后状态为 ACCEPTED,完成履约后为 COMPLETED。

## 取消与超时
- CREATED(待支付)状态可以主动取消,取消后库存回滚。
- 下单后 30 分钟未支付,系统自动关闭订单,状态变为 CLOSED,库存回滚。
- PAID 及之后的状态不能由用户直接取消,需要联系商家协商。

## 退款
- 平台首期未开放线上退款流程,订单表的 REFUNDED 状态仅为预留。
- 需要退款时请联系人工客服或商家处理,不要向用户承诺退款到账时间。

## 订单状态
- CREATED:待支付。
- PAID:已支付,待商家接单。
- ACCEPTED:商家已接单。
- COMPLETED:已完成。
- CANCELLED:用户已取消。
- CLOSED:超时未支付,系统关闭。
- REFUNDED:已退款,当前版本仅预留。

## 查询
- 用户只能查询自己的订单。
- 可以按订单号查询详情,订单号在订单列表中可以找到。
